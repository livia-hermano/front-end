# 💻 AUTO DRIVE

Este é um projeto desenvolvido para a avaliação de Front-End, focado em criar interatividade para um app de uma concessonária de carros esportivos de luxo.

## 🛠️ Tecnologias Utilizadas
* HTML5 (Semântica e Acessibilidade)
* CSS3 (Estilização e Feedback Visual)
* JavaScript (Manipulação de DOM e Eventos)

## 📁 Estrutura do Projeto
O projeto foi organizado seguindo boas práticas de mercado:
/
├── index.html
└── src/
    ├── styles/  (Estilos da página)
    ├── scripts/ (Lógica de interação)
    └── images/  (Ativos visuais)

## 🚀 Funcionalidades Implementadas
* **Interatividade Visual:** Elementos que reagem ao passar do mouse (Hover e manipulação de Classes):
Ao passar o mouse pelo banner a cor do seu fundo e de seu texto mudam, além de criar um efeito visual de "aproximação".
* **Saudação Dinâmica:** Mensagem de boas-vindas que muda conforme o horário local do usuário: 
A mudança da mensagem de boas vindas muda, onde antes de 12h é mostrada uma mensagem referente a "bom dia", entre 12h e 18h a mensagem muda para algo referente a "boa tarde" e depois das 18h a mensagem muda para algo referente a "boa noite";
* **Cálculo em Tempo Real:** Formulário que processa e exibe resultados assim que o usuário digita:
Ao colocar a distância da viagem, o usuário recebe a quantidade de litros que é necessário para fazer a viagem, em tempo real.
* **Injeção de Conteúdo:** Adição de novos itens na tela utilizando manipulação de DOM:
O usuário coloca os nomes dos modelos de carro que tem interesse e assim vai se criando uma lista dos seus itens escolhidos.
