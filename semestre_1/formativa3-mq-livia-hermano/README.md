# 💻 GalaxyTours

Este é um projeto desenvolvido para a avaliação de Front-End, focado em criar um site responsivo para uma agência de turismo espacial.

## 🛠️ Tecnologias Utilizadas
* HTML5 (Semântica e Acessibilidade)
* CSS3 (Estilização e Feedback Visual)
* JavaScript (Manipulação de DOM e Eventos)

## 📁 Estrutura do Projeto
O projeto foi organizado seguindo boas práticas de mercado:
/
├── index.html
└── src/
    ├── styles/  (Estilos da página)
    ├── scripts/ (Lógica de interação)
    └── images/  (Ativos visuais)

## 🚀 Funcionalidades Implementadas
* **Quebra de tela para tablets:** Utilizando Media Querys, foi definido que, para telas com no máximo 768px de largura, as colunas se dividiriam em 2 ao invés de 3 na seção de pacotes.
* **Quebra de tela para tablets:** Utilizando Media Querys, foi definido que, para telas com no máximo 480px de largura, as colunas se dividiram para ficar apenas uma coluna. O título e a frase também ficaram em uma coluna vertical, onde o texto fica centralizado. Além disso, a dica para computadores também desaparece da tela para smartphones.
